# Exotic Event & Entertainment — Available Image & Reference Archive

This ZIP packages the files that were actually recoverable from this conversation.
It contains 22 separate static image files, a local HTML gallery, and an inventory.

IMPORTANT: This is NOT the complete 3D/SVG/Lottie source asset library requested earlier.
No .glb, .gltf, .svg, .lottie, or Lottie .json source files were available to include.
A screenshot, render, or contact sheet does not contain those source files, even when their
filenames are printed in it. Nothing has been renamed to impersonate a model or animation.

## Contents

- public/assets/exotic/brand/ — original supplied raster logo reference (1 image).
- public/assets/exotic/model-posters/ — two separate static wedding-portal renders (2 images).
- public/assets/exotic/loader-posters/ — one static loader poster, not an animation (1 image).
- references/hero-designs/ — ten separate hero design images (10 images).
- references/full-homepage-designs/ — five full-homepage design images (5 images).
- references/library-previews/ — asset-board image, catalogue screenshot, contact sheet (3 images).
- index.html — offline image gallery; open after extraction, with no installation required.
- manifest.json — exact paths, dimensions, transparency flags, file sizes, checksums and notes.

## How to inspect and copy

1. Extract this ZIP.
2. Open index.html to inspect the separate images.
3. The small set of logo/poster files is organized under public/assets/exotic/.
   Copy the relevant files into your project as needed.
4. Keep references/ as a design-reference folder. Do not use a whole webpage screenshot
   as the functioning site. Rebuild text, buttons and content as real components.

## Important limitations

- The original logo is a 310 x 204 pixel raster screenshot, not a high-resolution vector master.
- Hero and homepage designs contain baked-in text and controls; they are not clean background
  photographs, reusable HTML, separate floral cutouts, or independently animatable layers.
- Rendered posters may help as still-image references or fallbacks, but are not editable models.
- The loader preview does not animate. manifest.json is an INVENTORY, not a Lottie animation.
- Treat statistics, testimonials, client/partner logos, phone numbers, email addresses, office
  locations and project histories shown in design mockups as unverified. Do not publish them
  as real business facts without confirmation.
- The original logo was supplied by the user. Other included files are images/preview outputs
  from this conversation; third-party marks depicted in mockups are not endorsements.
- Duplicate copies and an internal renderer test image were omitted.

No source asset has been recreated or added in this archive. All 22 images are preserved as
separate original files, with descriptive folder names rather than misleading extensions.
